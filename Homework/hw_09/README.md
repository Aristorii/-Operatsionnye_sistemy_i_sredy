---
**Задание:**
* Установить пакет `binutils` (если его нет) и создать простой файл на ассемблере (GASM) с расширением `.s` (например, `main.s`).
* Создать файл `Makefile` в каталоге проекта, в котором описать цели для компиляции (`main.o` из `main.s` с помощью `as`) и компоновки (`main` из `main.o` с помощью `ld`).
* Добавить абстрактные цели `clean` (для удаления объектных файлов) и `build` (для последовательного выполнения сборки и очистки), обозначив их в директиве `.PHONY`.
* Проверить работу: собрать программу одной командой `make build` и убедиться, что она компилируется.
----
В ходе работы я училась автоматизировать процесс сборки программ в Unix с помощью утилиты `make`. Сначала я подготовила исходный файл на ассемблере и проверила наличие компилятора. Затем я написала файл `Makefile`, в котором описали зависимости: чтобы получить исполняемый файл `main`, нужен объектный файл `main.o`, а для него, в свою очередь, нужен исходник `main.s`.
