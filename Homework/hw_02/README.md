**4.09.2026 Тема Практика по простым командам**
---
**Задание:**
* Перейти в `/var/log` и показать все файлы с расширением `.log`.
* Перейти в `/usr/bin` и показать файлы, отсортированные по размеру.
* Отобразить содержимое файла `/etc/apt/sources.list`.
* Найти в `/etc/passwd` все строки со словом `root`.
* В `/etc/services` вывести все строки без комментариев (комментарии начинаются с `#`).
* Найти в `/etc` все файлы и директории с расширением `.conf` или `.conf.d` (одной командой).
* Определить количество объектов типа «ссылка» в корневом каталоге (через `find` с типом `l`).
* Найти в `/usr/share` все каталоги на глубине не более 2 уровней.
* Найти в `/var` все файлы, принадлежащие пользователю `root`.
* Найти в `/etc` в пределах 2 каталогов все файлы, внутри которых упоминается пользователь `root` (используя `-exec` с `grep`).
---
В ходе работы я осваивала базовые команды командной строки Linux. Сначала я перешла в каталог `/var/log` и с помощью `ls *.log` показала нужные файлы. Затем в `/usr/bin` вывела список файлов, отсортированных по размеру, командой `ls -lS` (с флагом `-l`, чтобы видеть сам размер для проверки). Посмотрела содержимое файла `/etc/apt/sources.list` командой `cat` и нашла строки со словом `root` в `/etc/passwd` через `grep`. Для фильтрации комментариев в `/etc/services` я использовала `grep -v "^#"`, чтобы отсечь именно строки, начинающиеся с решётки. Далее с помощью `find` я нашла файлы с расширением `.conf` и `.conf.d`, посчитала символические ссылки в корне (их оказалось 8), нашла каталоги в `/usr/share` с ограничением глубины, файлы в `/var`, принадлежащие `root`, и файлы в `/etc`, содержащие упоминание `root` (через `-exec grep -l`).
