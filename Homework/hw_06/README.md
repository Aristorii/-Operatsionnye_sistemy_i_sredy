**Задание:**
* Установить и запустить консольный мультиплексор `tmux`, понять разницу между его окном и обычным терминалом.
* Создать новое окно (Ctrl+B, C), переименовать текущее окно в `Text` и запустить в нём `vim`.
* Написать в `vim` скрипт на Python, который записывает в файл `test.txt` количество секунд с момента запуска (каждое значение с новой строки), и запустить его.
* Переключиться на первое окно (Ctrl+B, 0), следить за изменением размера файла `test.txt` с помощью `watch`.
* Прервать выполнение скрипта и `watch`, перейти в первое окно (Ctrl+B, 1) и закрыть второе окно командой `exit`.
* Разделить окно по горизонтали (Ctrl+B, `%`), установить `fastfetch` в правой области, запустить его в левой, затем закрыть правую.
* Разделить окно по вертикали (Ctrl+B, `"`), поэкспериментировать с разделением и закрыть все области.
