# Практические материалы

В этой папке собраны все домашние задания по дисциплине «Операционные системы и среды»
---
Структура:

Внутри каждой папки лежит два файла:

1. README.md — файл с отчетом (текст, что было за задание / что я делала).

2. Документ с самой работой (например, .docx с заданием или выполненной работой).
