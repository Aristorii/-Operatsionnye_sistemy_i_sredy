---
**Задание:**
* Создать каталог `work` в домашней директории, перейти в него и вывести текущий путь.
* Создать пустой файл `file.txt` командой `touch`.
* Заполнить файл текстом (первые два абзаца из «Гарри Поттера»), записывая каждое предложение с новой строки, используя `echo`.
* Переименовать файл в `book.txt` и убедиться, что текст вставлен корректно.
* Найти все предложения со словом `was` и записать их в новый файл `was.txt`.
* Объединить `was.txt` и `book.txt`, а затем посчитать, сколько раз в них встречается буква `n` (через `grep` и `wc`).
---
В ходе работы я осваивала команды для работы с файлами и перенаправления потоков в Bash. Сначала я создала папку `work`, зашла в неё и проверила путь командой `pwd`. Затем создала пустой файл через `touch` и с помощью `echo` с оператором `>>` добавила в него текст из книги, записывая каждое предложение на новой строке. После этого я переименовала файл командой `mv`, прочитала его через `cat` и с помощью `grep` отфильтровала строки со словом `was`, сохранив результат в отдельный файл. В конце я объединила файлы командой `cat` и посчитала количество букв `n` с помощью связки `grep -o` и `wc -l`. В результате я научилась создавать и редактировать файлы, перенаправлять вывод команд в файлы и искать нужную информацию по тексту.
