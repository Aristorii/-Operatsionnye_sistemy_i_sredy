**Задание:**
* Ответить на вопрос: в чём отличие использования команд `exit` и `return` в Bash.
* Написать функцию, которая выводит текст в поток, заданный пользователем в аргументе (стандартный вывод, поток ошибок или файл).
* Написать функцию для вывода информации о системе, принимающую аргумент с описанием параметра (`pwd`, `user`, `version` и т.д.), и показать её использование.
* Написать функцию, которая выводит значение переменной по её названию (с использованием `eval`), и программу, которая работает до нажатия Ctrl+D (EOF).
---
В ходе работы я изучала создание и использование функций в Bash. Сначала я разобралась с вопросом: `exit` завершает работу всего скрипта или оболочки, а `return` завершает только выполнение функции и возвращает код возврата. Затем я написала функцию, которая с помощью конструкции `>` или `2>` выводит текст в нужный поток в зависимости от аргумента (stdout, stderr или файл). Для второй функции я реализовала блок с `case`, который по аргументу (например, `pwd` или `user`) вызывает нужные команды и выводит информацию о системе. Третью функцию я сделала с помощью `eval`, чтобы она могла обратиться к переменной по её имени, и обернула её в цикл `while read`, который продолжается до появления EOF (Ctrl+D).
