# Теоретические материалы

Лекции и методички к практическим работам по дисциплине «Операционные системы и среды».

## Теория

| № | Название файла | О чём |
| :--- | :--- | :--- |
| 1 | `Автоматизация сборки.pdf` | Изучение утилиты `make`, написание Makefile, компиляция программ из ассемблера и работа с целями `build` и `clean`. |
| 2 | `Администрирование.pdf` | Управление процессами в Linux (`ps`, `grep`), работа со справкой `man`, фильтрация задач по пользователю и ресурсам. |
| 3 | `Приложения.pdf` | Работа с консольным мультиплексором `tmux`, написание скриптов на Python в редакторе `vim` и мониторинг системы. |
| 4 | `Простые команды Bash 2 .pdf` | Базовые команды Linux (`ls`, `cat`, `grep`, `find`), создание каталогов, переименование и объединение файлов. |
| 5 | `Создание демонов.pdf` | Разработка bash-скриптов для записи в журнал, создание unit-файлов `systemd` и запуск пользовательских служб. |
| 6 | `Создание снимков ВМ.pptx` | Работа с виртуальными машинами в VirtualBox, создание снапшотов, симуляция сбоя системы и восстановление состояния. |
| 7 | `Функции Bash.pdf` | Написание и использование функций в Bash, работа с аргументами, перенаправлением вывода и переменными. |
| 8 | `Файловая система.pdf` | *(Теоретический материал)* Работа с дисками, таблицами разделов, файловыми системами FAT, NTFS и ext4. |
